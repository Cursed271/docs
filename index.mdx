## What lives here

This homepage is built around Mintlify’s MDX-based docs flow, where each page is stored in your repository and the site navigation is configured through `docs.json`. Mintlify’s docs also show landing pages commonly using hero content plus navigation cards, which makes this layout a natural front door for a wiki. \[web:73\]\[web:66\]\[web:63\]

## Writing rules

<Check>
  One page should answer one clear question.
</Check>

<Check>
  Every project should have an overview, setup guide, architecture note, and changelog.
</Check>

<Check>
  Prefer short pages with strong internal links over giant walls of text.
</Check>

<Check>
  Put commands, assumptions, and prerequisites near the top.
</Check>

<Check>
  End important pages with related links so readers keep moving.
</Check>
